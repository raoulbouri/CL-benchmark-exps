## Projection to full schedules

Written 3 Oct 2026 from the measured numbers above. **Estimates, accurate to roughly ±30%.** Evaluation times were partly measured while other jobs shared the machine. Phase 2's first full runs are the real calibration.

### How the numbers were derived
- **DMPEL training, LIBERO-Long.** LIBERO-Goal (full schedule, 3 seeds, GPU shared with another run) averaged **38.4 min per task** (range 28–55). LIBERO-Long has 138,090 training frames against Goal's 63,728 (**×2.17**), so about 83 min per task, **13.9 h for 10 tasks** under contention. A run alone on the machine was about 41% faster per epoch (1.7 vs 2.9 min measured on Goal), so about **8 h** with the other GPU idle.
- **DMPEL evaluation.** Micro-runs: 1.4 min per task-evaluation (20 episodes), 2.35 min held-out (40 episodes). A 10-task run evaluates 1+2+…+10 = **55** task-evaluations: 1.3 h (original) or 2.2 h (held-out).
- **CLARE, training vs evaluation separated.** Within one run, stage 0 evaluates 1 task and stage 1 evaluates 2, so two stage times give both unknowns. Original protocol, stage times 20.1 and 34.9 min: **evaluation = 14.8 min per task-evaluation (100 episodes), training+discriminators = 5.3 min for 2,200 steps**. Held-out, 12.9 and 19.2 min: 6.3 min per task-evaluation (40 episodes) and 6.6 min training. Training is about **0.16 s per step**, so the paper's 10,000 + 2,000 steps cost about **33 min per task** (5.5 h for 10 tasks). Evaluation uses 55 task-evaluations: **12–15 min each, 11–14 h** (original) or **5.8 h** (held-out).
- **CLARE-codebase ER.** The same separation on its micro stage times (22.8 and 36.2 min) gives about 9.4 min training for 2,000 steps (0.28 s per step, because each step also draws a replay batch) and 13.4 min per evaluation.

### Phase re-estimates
- **Phase 2** (DMPEL ×2 seeds + CLARE ×2 seeds, original protocol): 2×15 + 2×18 = **≈ 66 GPU-h**, or **≈ 82** with held-out re-scoring (+4.4 for DMPEL, +11.6 for CLARE). The plan's ≈ 75 is within 10%. With two GPUs in parallel this is about **2 days** of wall time.
- **Phase 5.** Using the unit costs, 3 seeds each of DMPEL (≈ 48) and CLARE (held-out, ≈ 35) already cost **≈ 83 GPU-h** before any ER cell. The plan's cap of 250 GPU-h therefore leaves about 165 for ER cells: **nine runs (3 budgets × 3 seeds) fit only if each costs ≲ 18 GPU-h.** If the 2-GPU DMPEL-codebase ER run costs more than about 9 h of wall time, the cap will not hold. This is a planning-discussion item, to be settled once attempt 7 gives the ER number.
- **Phases 3 and 4** are not re-estimated here; Phase 3 (re-pretraining CLARE's base for 200k steps) depends on a step-time measurement that has not been made.
